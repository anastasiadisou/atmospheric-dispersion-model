# Atmospheric Dispersion Model

A lightweight Gaussian puff atmospheric dispersion model developed in
Python for the simulation of pollutant transport and dispersion from a
point source.

The model uses surface and upper-air meteorological observations,
land-use information, and source characteristics to calculate hourly
micrometeorological parameters and simulate the evolution of Gaussian
puffs over a user-defined computational domain.

the preprocessing scripts. It does not need to contain files before the
workflow is executed.

## Requirements

The model requires Python 3 and the following packages:

-   NumPy
-   Matplotlib

Install the required packages with:

``` bash
pip install -r requirements.txt
```

The remaining modules used by the scripts belong to the Python standard
library.

## Required input data

### Surface meteorological observations

Place the raw NOAA Integrated Surface Database (ISD) file in:

``` text
input/surface/
```

The same ISD file is used by `surface_from_isd.py` and
`wind_from_isd.py`.

Before execution, set `YEAR` and the input filename in the
`USER SETTINGS` section of both scripts.

### Upper-air observations

Place the raw NOAA Integrated Global Radiosonde Archive (IGRA) file in:

``` text
input/upper_air/
```

The same IGRA file is used to estimate the vertical diffusion
coefficient `Kz` and the mixing height `zi`.

Set `YEAR` and the IGRA filename in the `USER SETTINGS` section of
`kz_from_igra.py` and `zi_from_igra.py`.

### Land-use grid

The model requires a prepared ESRI ASCII Grid:

``` text
input/land_use/landuse.asc
```

The land-use grid is prepared externally in QGIS and is therefore
supplied directly as an input to the model.

The current micrometeorological parameter table supports the GLCC
classes:

``` text
1, 2, 6, 8, 9, 16
```

If the land-use grid contains another class, an explicit mapping must be
added to `LU_PARAMS` in `micromet_calculations.py`.

### Emissions

The dispersion model can operate with either a constant emission rate or
a time-varying emission file.

For a constant emission rate, set:

``` python
EMISSION_MODE = "constant"
Q_CONSTANT_G_S = 20.0
```

where the emission rate is expressed in g/s.

For time-varying emissions, set:

``` python
EMISSION_MODE = "file"
```

and place the emissions file in:

``` text
input/emissions/emissions.csv
```

The file must contain an `hour_index` column and an emission-rate column
in g/s. The name of the latter is specified through `EMISSIONS_COLUMN`
in `dispersion_model.py`.

## Workflow

Run the scripts from the repository root in the following order.

### 1. Process surface meteorological data

``` bash
python preprocessing/meteorological_data/surface_from_isd.py
python preprocessing/meteorological_data/wind_from_isd.py
```

These scripts generate:

``` text
processed/surface_from_isd.csv
processed/wind_from_isd.csv
```

### 2. Process upper-air data

``` bash
python preprocessing/meteorological_data/kz_from_igra.py
python preprocessing/meteorological_data/zi_from_igra.py
```

These scripts generate:

``` text
processed/kz.csv
processed/zi.csv
```

### 3. Calculate micrometeorological parameters

``` bash
python preprocessing/micrometeorology/micromet_calculations.py
```

This step combines surface meteorology, mixing height, and the land-use
grid and generates:

``` text
processed/micromet_fluxes.csv
processed/micromet_grid.npz
```

### 4. Run the dispersion model

Before running the model, edit the `USER SETTINGS` section of:

``` text
model/dispersion_model.py
```

Specify:

-   simulation year and requested period;
-   spin-up period;
-   computational-grid dimensions, resolution, and origin;
-   source coordinates;
-   stack height and diameter;
-   exit velocity and exit temperature;
-   constant or time-varying emission rate;
-   output options.

Then run:

``` bash
python model/dispersion_model.py
```

The model calculates the mean concentration field for the selected
simulation period. Output filenames are generated automatically from the
requested date or date range.

## Main model formulation

The model represents atmospheric emissions as a sequence of Gaussian
puffs. Each puff is advected using the hourly horizontal wind components
and grows according to turbulence-dependent dispersion parameters.

The preprocessing chain provides the quantities required by the
dispersion calculation, including friction velocity, Monin-Obukhov
length, convective velocity scale, mixing height, and vertical
diffusivity.

The dispersion calculation includes:

-   Briggs-type buoyant plume-rise estimation;
-   land-use-dependent horizontal dispersion;
-   stability-dependent turbulent velocity fluctuations;
-   Lagrangian time scales;
-   Taylor variance growth;
-   anisotropic horizontal dispersion;
-   vertical reflection at the ground and mixing-layer top;
-   crosswind puff splitting;
-   sub-hourly puff transport and concentration calculation.

Concentrations are calculated in µg/m³.

## Important assumptions

The current implementation uses a spatially uniform hourly horizontal
wind field across the computational domain. Land-use and
micrometeorological properties can vary spatially through the gridded
input data.

Terrain effects and building downwash are not represented in the current
implementation. Atmospheric chemistry and dry/wet deposition are also
not included; the emitted pollutant is treated as a conserved tracer.

## Notes

Input datasets must cover the selected model year and use the formats
expected by the preprocessing scripts.

The number of annual hours is calculated automatically from `YEAR`,
allowing both normal years (8760 hours) and leap years (8784 hours).

The scripts contain a `USER SETTINGS` section so that a new application
can be configured without modifying the core calculation routines.
